# AGENTS.md — CrystalViz

Blender **Extension** `crystalviz`. Imports CIF (crystallographic) files via **gemmi** (bundled, in-process — no subprocess, no pip for users) and renders atoms/bonds with Geometry Nodes. GPL-3.0-or-later (the bundled gemmi stays MPL-2.0).

## What this repo is

- Targets **Blender 5.2+**, which ships **CPython 3.13** — that's why `build_extension.py` hardcodes `_PY_TAG = "cp313"` and only downloads cp313 wheels.
- `bl_info` in `__init__.py` is legacy; `blender_manifest.toml` governs extension builds. Keep both in sync on version bumps.
- `tests/` holds the headless Blender suites (`pwsh tests/run_all.ps1`). CI (`.github/workflows/python-quality.yml`) runs ruff, formatting, `compileall` and bandit only — there is no headless Blender in CI, so functional verification is still manual (below). Never claim a feature works without it.
- Never trust a CIF to be complete: validate input and fail with a meaningful message; don't reinvent math gemmi already provides.

## Build & release

```bash
python build_extension.py download [--gemmi-version 0.7.5] [--force]  # wheels/ + regenerate manifest
python build_extension.py build [--platforms macos-arm64]            # dist/*.zip per platform
blender --command extension validate                                 # from this directory
blender --command extension build --split-platforms                  # cross-check the script's output
```

- `download` must run before `build` (build refuses to run without `wheels/`).
- **`blender_manifest.toml` is GENERATED.** `write_manifest()` rewrites it from `_MANIFEST_TEMPLATE` in `build_extension.py`. To change id/version/platforms/permissions, edit the template, not the toml — or your edit is silently clobbered on the next `download`.
- Version lives in **three** places: `_MANIFEST_TEMPLATE`, `blender_manifest.toml` (regenerated by the template), and `bl_info["version"]` in `__init__.py`. Bump all three before release.
- `_PACKAGE_FILES` in `build_extension.py` lists exactly what goes into each zip. A new add-on source file, asset, or data file is silently NOT shipped unless added to that list.
- Adding a target platform requires 4 coordinated edits: `TARGET_PLATFORMS`, `_PLATFORM_TAG`, `_PLATFORM_ARCH`, and `platforms` in the template.
- `wheels/*.whl` are gitignored (regenerated by `download`); the built `dist/*.zip` **are committed** ("Add builded Extension" commits). Rebuild and commit `dist/` when the add-on changes.

## Architecture

Three-module split — respect it:

- **`gemmi_worker.py`**: all crystallography (CIF parsing, symmetry expansion, P1 sites, growth). Pure Python + `gemmi`; imports no `bpy`, so it must stay runnable standalone for testing. The add-on calls only `load_structure()` and `grow_connectivity_shell()` (both call sites go through the lazy import helper `_gemmi_worker()` — keep it that way, it delays `import gemmi` until an operator actually runs).
- **`chemistry.py`**: bond-order and aromatic-ring perception for the ChemDraw depiction (`bond_orders()`, `find_rings()`, `aromatic_rings()`, whose `detail=True` records carry the lone-pair share of the sextet, whether a Kekulé depiction exists, and any haptic metal). Pure standard library — no `bpy`, no `gemmi`, no numpy — so it is unit tested in plain CPython (`tests/test_chemistry.py`). It takes a plain graph (`{node: symbol}`, `(a, b)` edges, optional normalised lengths) and never touches Blender or crystallography; `__init__.py` adapts display segments to it through `_chemdraw_graph()` and the lazy `_chemistry()` helper.
- **`__init__.py`** (~4.2k lines): everything Blender — operators (`cgn.*`), panels (`CGN_PT_*`), Geometry-Nodes groups, materials, viewport drawing. Don't move display logic into the worker.

ChemDraw contract: multiple-bond orders come from valence bookkeeping — a tier-1 oxo-pattern pass seeds and reserves the genuine terminal `X=O` doubles of sulfone/sulfonate/triflate `S(=O)₂`, selenone/tellurone, nitro/nitrate `N(=O)₂`, phosphate `P=O` and carbonyl `C=O` (ketone, aldehyde, ester) straight from the geometry before anything else (count = min(target valence − covalent degree, terminal-O count, 2), shortest first; only `VALENCE_LADDERS` neighbours count as covalent, so a cation salt can never hide a double). A carbonyl seed is skipped when the carbon bonds a metal (a metal carbonyl/acyl is left to the forced-triple/greedy passes) and only fires on a C–O short enough to be an oxide (`_C_CARBONYL_MAX_LENGTH_SCALE`, 0.90 of the radii sum), so a phenoxide or enol whose proton is missing from the graph keeps its single bond and its ring keeps the aromaticity. Then a forced-triple pre-pass for an atom with two spare orders and one usable bond (an alkyne/nitrile partner that is itself saturated, or a ring carbon whose extra order is spent inside its ring; a metal carbonyl M–C≡O whose carbon's every other neighbour is a dative metal triples its C–O even though the oxygen wants only one spare order — the positive charge sits on the metal, so the plain ladder alone cannot ask for it), greedy matching, augmenting paths, bounded repair — aromatic rings from Hückel counting on the resulting Kekulé structure. Per-pair bond-length gates (`_candidate_max_length_scale()`) only bound which edges *can* carry an order (the oxo seeds included); they never decide aromaticity, which is still the Hückel count alone. A ring atom's multiple bond to a non-ring atom (C=O) vetoes the ring; a fusion bond to another ring atom does not. A double bond to a terminal carbon (degree one, same element) is exempt: a grown graphite/graphene patch ends in dangling carbons that the Kekulé structure doubles, which is a truncated lattice rather than an exocyclic C=CH2 — with hydrogens present that carbon has a second neighbour and the veto still fires. A three-connected N carrying exactly one terminal O is an N-oxide: it is four-valent, its N-O bond is dative (excluded from the candidates) and its fourth order goes into the ring, without which the ring has an odd number of unsaturated carbons and no Kekulé structure exists at all (pyridine N-oxide, pyrazine N,N′-dioxide); a nitro/nitrate N (two or three terminal O) is drawn N(=O)₂ with two genuine double bonds, and a two-connected nitroso N=O is left alone. The oxide is keyed on the N–O length, not the graph alone: only a short N–O (≤1.0 of the covalent-radii sum — CSD pyridine-oxide median 0.975, N–OH ≈1.03, `_N_OXIDE_MAX_LENGTH_SCALE`) promotes the nitrogen, so an N–OH ring stays three-valent and non-aromatic even when the CIF graph omits the hydroxyl hydrogen (`_terminal_oxygens` applies the gate for nitrogen centres only; chalcogen oxides are never length-filtered because an S–OH is as short as an S=O). A diazo (`R₂C=N⁺=N⁻`) or azide (`R–N=N⁺=N⁻`) terminal N–N chain is booked from geometry as well: a degree-one N bonded to N through a very short N–N (≤0.90 of the radii sum) is the two-valent N⁻, and its middle N partner — whose other bond is itself short enough to be a double — is the four-valent N⁺, so both C=N and N=N are drawn double and the diazo carbon reaches its four bonds; a diazonium's long C–N leaves the old depiction (`_DIAZO_MAX_LENGTH_SCALE`, `_DIAZO_PARTNER_MAX_LENGTH_SCALE`). A 4-connected group-15 centre is P(=X)R₃, a genuine ylide P=C, or a saturated cation/complex, which the (3, 5) ladder cannot tell apart — so the rung-5 order is withheld when the centre has a metal neighbour (a phosphine/arsine complex: the CSD types every P–C of such a centre Single, even ADAKIB's 0.965 gold-bound ylide — the dative metal consumes the 5th rung) or an all-C/H substituent set whose bonds are all too long for a P=C double (a true phosphonium stays four-valent, `_P_YLIDE_MAX_LENGTH_SCALE` = 0.97 of the radii sum), and only a short P=C keeps the rung and its double (BEDLON, HINVAB). A P=S/P=Se/P=N double survives even when the chalcogen or nitrogen also coordinates a cation: the partner is granted its missing order when its *sole* ladder neighbour is a group-15 pnictogen (LEVQUZ's cerium thiophosphoryl complex, AVEYAE's metal-bound phosphinimines), while a three-connected phosphinimine N (P + C + metal) is promoted only when its pnictogen is itself a plain R₃P= centre — a P that already holds a metal (UJITAI's Zr-bound phosphine) keeps its P–N single, exactly as the CSD types it — and a bridge with two ladder neighbours (a thiolate P–S–C) is never promoted. A metal bond is dative, so a ring nitrogen that coordinates a metal still reaches its ligand valence: it is promoted to one ring double only when a carbon of its ring is otherwise left with three bonds (a pyridine, whose five carbons cannot pair up, or a five-ring whose conjugation an exocyclic double has broken - the dipyrrin of EDOBEG), while a pyrrole/pyrrolide nitrogen keeps its lone pair because its four carbons pair among themselves (`_promote_metal_ring_nitrogens`; the CSD types 92.7% of the N-C ring bonds of a metal-bound six-ring N Aromatic). A bond between two ring atoms that belongs to no ring is a biaryl link and stays single while a ring double is available, so a short link cannot steal the double bond of the ring (EDOBEG's C34-C21 at 1.392 A lost the pyrrole C34=N2 and stranded a phenyl carbon); it is relaxed only for a ring that still has an unsatisfied atom, which keeps a genuine inter-ring C=C (bifluorenylidene) double (`_ring_link_bonds`, `_link_bonds_to_relax`). A conjugated six-membered sulfur ring is the pyridine analogue: thiopyrylium and thiabenzene 1-oxide take a genuine S=C ring double (one extra order, two when a terminal O is drawn S=O), so the ring's sextet has no lone-pair share. That extra order needs a six-membered ring whose chalcogen–C bonds are all shortened (`_RING_CHALCOGEN_MAX_LENGTH_SCALE`); thiophene (five-ring, where an all-double-bond Kekulé has an odd number of orders) keeps its lone pair, a saturated ring stays single, and a sulfone S (two terminal O) is not walked as a ring atom (it is hexavalent: the tier-1 oxo pass seeds both S=O doubles itself because the centre's own valence rung would ask for none — the reserved edges ride the terminal oxygens, never a ring bond). A terminal oxygen keeps its oxide role even when a cation also coordinates it: a metal salt of a sulfone contacts every S=O oxygen (Ca-O/K-O in a calcium sulfonate hydrate), so such an O has graph degree two but is still terminal — only a second *covalent* neighbour (H, C) hides the oxide. That O then carries its one extra order from its own deployment (`_initial_deficit` gives a terminal N-O/S-O oxygen deficit 1 for the double even when its ladder is already full), so the greedy pass pairs S=O before any S-C. The length gate only decides whether the chalcogen contributes a ring double bond — aromaticity is still the Hückel count on the resulting Kekulé structure. Selenium and tellurium reuse the whole rule (`_SIX_RING_CHALCOGENS`): selenopyrylium/telluropyrylium take a ring C=Se/C=Te double, selenophene/tellurophene keep their lone pair, and a selenoxide keeps its Se=O. A ring chalcogen's terminal S=O/Se=O/Te=O is exempt from the exocyclic-veto rule, but only once that chalcogen already carries a ring double bond. Arsenic and antimony mirror phosphorus through the group 15 valence ladder `(3, 5)`: arsabenzene/stibabenzene take an As=C/Sb=C ring double, while a five-membered arsole/stibole keeps its lone pair. A three-connected boron has an empty p orbital, so a ring boron with no double bond contributes 0 π electrons instead of rejecting the ring (borazine, boroxine are aromatic from the N/O lone pairs); a carbon in the same position still rejects it. A ring containing boron is an aromatic network, not a fused pi system: a nitrogen or oxygen shared by several rings still donates its lone pair, so an h-BN sheet is aromatic ring by ring (unlike an indolizine), and since its borons carry no B=N/B=O double bond there is no alternating arrangement to draw, so the ring keeps its torus (borazine, boroxine). A heteroatom donates its lone pair only to a ring it belongs to alone: the bridgehead nitrogen of an annulated indolizine (or any N/P/O/S shared by two rings) hands it to neither, so both rings are drawn Kekulé (indole and pyrrole, with the heteroatom in one ring, stay aromatic). A ring whose sextet does include a heteroatom lone pair is aromatic but is still drawn Kekulé when such an arrangement exists: it has one unique arrangement of alternating bonds, which IUPAC GR-6.3 prefers over a delocalisation curve — `_classify_aromatic_rings()` reads `AromaticRing.lone_pair_electrons` and `AromaticRing.kekule` for that, so pyrrole/furan/azoles show their doubles (a fused thiophene whose doubles sit on its fusion bonds still does), while borazine and an h-BN sheet have none and keep their tori. The opposite case is a coordinated π ligand: a ring whose atoms all bond the same `HAPTIC_METALS` member is the 6π η5-Cp/η6-arene ligand and keeps its torus (GR-1.7.2), which is why `find_rings()` counts non-metal neighbours for a metal-bonded atom. `HAPTIC_METALS` includes the group-1 metals (Li/Na/K/Rb/Cs), so a genuine alkali π salt is recognised too: a potassium π salt of a pyrrolide, whose K+ contacts every ring atom (AVAVUO's K1, and BAQVEU), keeps its aromatic torus. The haptic path only fires when the Kekulé count already failed, so an alkali cation that merely bridges a ring nitrogen (CEMGAD's Na) never converts the ring into a π ligand. Any ring atom with more than three neighbours is still walkable when the excess neighbours are metal contacts: `_ring_eligible` counts the `NONMETALS` (H, D, B, C, N, O, F, Si, P, S, Cl, As, Se, Br, Te, I) neighbours directly against the 2–3 limit, so a pyridine nitrogen bridging two sodium cations (CEMGAD's Na-coordinated phenanthrolines) is enumerated through its NONMETALS count, even though the alkali bridge is exactly the case the haptic gate above refuses — the dative contact does not consume the lone pair. `HAPTIC_METALS` keeps its separate job of recognising genuine pi ligands in `_haptic_pi_electrons`. After the valence repair the aromatic rings are re-Kekulé-ed to maximise the number of Hückel-valid rings (Clar's rule, terminal rings preferred): the shortest-edge-first repair can otherwise spend a fusion double on a neighbouring ring and leave a pyridine one electron over its sextet (AHUCIT's thiophene-fused dipyridine), while another matching of the same cluster closes both. The re-placement covers fused clusters *and* singleton rings — a lone ring invalidated by the repair is re-placed just as a fused one, so ALIGUA's aluminium pyrazolides (each pyrazolide nitrogen binds a different Al, leaving the ring short of a sextet) are closed to a genuine 6π ring even though nothing is fused; fused clusters are walked first so the shared budget is spent where the fused search needs it, and an already-aromatic singleton costs one seed `evaluate` step. The re-placement only rewrites bonds of the re-placed rings, keeps at most one ring double per atom, applies the same length gate and valence capacity as the repair (a saturated sp3 or exocyclic-carbonyl carbon takes none; a nitrogen of a single ring may be promoted to a pyridinium/N-oxide-type double — the fresh promotion is nitrogen-only, so a ring chalcogen or pnictogen (S, Se, As, Sb, ...) atom keeps its lone pair and can never be given an Sb=N by the Clar pass — but only when every oxygen it binds is a genuine short terminal N-oxide, an N-OH whose N-O is too long, or whose oxygen holds a second covalent neighbour, stays three-valent exactly as in `_terminal_oxygens`, so the Clar pass cannot invent the N-oxide sextet the repair's gate refuses; and at most one ring atom is promoted per ring, so an intrinsically 8π ring (a diazastibolene's N–C=C–N–Sb, where two promoted N plus the Sb lone pair would re-read as a fake 6π sextet) stays C=C single-bonded and non-aromatic; a bridgehead heteroatom keeps its lone pair for the fused system unless the repair already asked for one), leaves a haptic-metal ring alone, and is bounded by cluster size and a step budget. The search walks the ring atoms fewest-remaining-order-first (MRV) and tries the seeded edges (the repair's own double candidates, shortest first) before fresh ones, and stops as soon as every ring of the re-placed set validates: the `terminal` count is a topological property of the cluster, not of the placement, so an all-valid early stop cannot drop a better arrangement. The step budget is one shared `_CLAR_STEP_BUDGET` counter across the whole structure's clusters, consumed in `_fused_ring_clusters()` order — a large early cluster can starve the later ones, which then keep the repair's arrangement (budget-exhausted clusters still count against `missing` rings on the CSD corpus, so treat budget changes as a corpus-wide trade-off against per-entry runtime). Rings are enumerated 5–7 members, bounded by a step budget, so keep the searches bounded when touching them. Delocalised oxo groups are a display-only overlay on top of that perception: `chemistry.delocalised_oxo_edges()` returns every terminal X–O bond of a centre whose oxo budget is smaller than its terminal-oxygen count (carboxylate/carbonate, nitrate, phosphate/phosphonate, sulfate/sulfonate, Se/Te analogues), and `_chemdraw_segments()` draws each as a ChemDraw 1.5 bond — one solid stroke plus a dashed second stroke (a run of short collinear order-2 edges, `_CHEMDRAW_DASH_LENGTH`/`_CHEMDRAW_DASH_GAP`) at the multiple-bond spacing. Nitro `N(=O)₂` and sulfone `S(=O)₂` spend their whole budget and keep their genuine doubles; a lone carbonyl, sulfoxide or N-oxide is never delocalised. The overlay is gated by the `Scene.cgn_delocalised_bonds` toggle (default on, under ChemDraw) and never changes `bond_orders()` or the CSD order matching (the CSD's own "Delocalised" type is excluded from scoring, and its 2D depiction draws such bonds dashed only where the oxygen also coordinates a metal, which is coordination-driven and not a deterministic geometric rule).

Data flow and storage contract:

- Import → `worker.load_structure()` returns a dict: P1 `sites`, flat `instances` list of **quadruples** `(site_index, tx, ty, tz)`, `cell_matrix` (9 floats, column-major orthogonalized cell vectors, read from gemmi's _private_ `unit_cell._columns` — re-check this attribute if the bundled gemmi version changes), space-group XHM + operator triplets, cell-params display strings (with standard uncertainties).
- Dummy and empty sites are dropped at load: a site whose CIF `_atom_site_calc_flag` is `dum` (the `Cg` ring centroids of cyanoferrocene, COD 2005233) or whose occupancy is 0 never reaches the site table. gemmi exposes no `calc_flag` on its sites, so `_dummy_labels(block)` reads the tag from the CIF block; without it the label fallback in `_site_element` parses `Cg1` as carbon and the dummy bonds to every atom of the ring it marks.
- All structure state is persisted as **JSON strings in collection custom properties** `cgn_*` on the structure collection (`cgn_role == "structure"`); the active one is looked up via `scene.cgn_active_structure`. Fill/Grow/Delete (`cgn.fill_*`, `cgn.grow_*`, `cgn.delete_atoms`) re-derive atoms from sites+instances (`_materialize_atoms`) — they never rebuild from the CIF. Fills build **no bonds** (`_clear_bonds` drops the previous set) and import builds none either (`_import_result` only stores the default connectivity pairs, like Fill → Asymmetric Unit); grow appends to existing bonds, but falls back to a full build when the structure has no bond objects (i.e. right after a fill or import), so the initial atoms get bonded — even when a growth adds no shell (finite molecules like Ferrocene.cif / multiple_bonds.cif).
- Structures imported before the site table existed raise `_LEGACY_STRUCTURE_ERROR`; they must be re-imported, they cannot be grown/bonded.

## cctbx parity (don't break)

`gemmi_worker.py` reproduces cctbx output exactly on the example CIFs. Changing symmetry code breaks it unless you preserve:

- element symbol resolved from the CIF `type_symbol` first (`_site_element`);
- duplicate CIF block names read with `check_level=0`, last block wins.

Any symmetry/coordinate change should be validated against the example CIFs (same P1 sites, order, instances).

## Units

Worker speaks **Ångström**; Blender converts with `_DISPLAY_SCALE = 0.1` (1 Blender unit = 10 Å ≈ scene scale where 1 Å = 1 cm). Keep conversions in one place (`_display_point`, radius helpers). Preserve fractional coordinates, unit-cell parameters, space-group info and symmetry operators end to end.

## Verification (manual)

- Suites: `pwsh tests/run_all.ps1` (optionally `-Only "*polyhedra*"`); expected 58/58 — see `tests/README.md` for the archived groups.

- Syntax: `python -m py_compile __init__.py chemistry.py gemmi_worker.py` (note `__init__.py` imports `bpy`, so compile only).
- Worker standalone: `pip install gemmi` and run/ad-hoc-test `gemmi_worker.load_structure(...)` in a normal Python — no Blender needed.
- Chemistry standalone: `python tests/test_chemistry.py` (plain CPython, no Blender, no gemmi).
- Example CIFs live in **`CIF/`** (all COD entries, provenance in `CIF/README.md`): `multiple_bonds.cif` (organic, ADPs + bond table), `Brookite.cif` (polyhedra), `Ag2Cr2O7.cif` (polyhedra/grow), `Ferrocene.cif` (organometallic), `Nano.cif` (2048 P1 sites — use for performance/atom-count limits like `_MAX_FILL_ATOMS = 200000`), plus `Chalco`, `Cu`, `Cu2O`, `Diamond`, `Graphite`, `BN`.
- In Blender: install the built zip from `dist/`, check Add-on Preferences shows the bundled gemmi version, import, Fill/Grow, toggle all four models (`BALL_STICK` / `ELLIPSOID` / `SPACE_FILLING` / `WIRE_STICKS` — note the ORTEP mode's `cgn_model` enum value is `ELLIPSOID`, not "ORTEP").
